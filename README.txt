TRAVEL GUIDE

This is a simple Travel Guide web project.

Technologies Used:
- HTML
- CSS
- JavaScript
- PHP
- MySQL

How to Run:
1. Start Apache and MySQL from XAMPP.
2. Put the project folder inside C:\xampp\htdocs\
3. Open phpMyAdmin.
4. Create a database named travelGuide.
5. Import database.sql.
6. Open http://localhost/travel/

Admin Login:
Email: admin@travel.com
Password: 1234

The project includes Visitor, General User, Scout and Admin features.
